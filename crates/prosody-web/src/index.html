Palette — changes how it sounds, never what happens

Mix

The poem decides where in the tempo range it sits, from how densely its syllables pack into bars. Everything else here is colour. Humanise strays each syllable a little late and soft, drawn from its own line, so the same poem always strays the same way.

Mappings — changes what happens

AB

Candidate mappings still under review. Each is a selector: choose a variant — or off — for each setting, then switch between A and B while it plays; the Score tab measures both. A bold border marks a choice that is not the default.

Reading — the poem spoken over the music

Whether and when lines are read is the reading mapping above: arrives speaks each line once, in the bar where it is first heard; stanza reads a stanza's lines one a bar from where it is first heard, so a stanza that transforms a loop is read through rather than a line every few bars; off reads nothing. Each line is fitted to its bar at the piece's tempo; loops, lanes and the outro are never read. Strudel's clock fires each line; your browser's voice speaks it.
